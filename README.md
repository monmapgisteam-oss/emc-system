# Эрдэнэт Үйлдвэр — Нэгдсэн мэдээллийн систем

4 хэлтсийн ArcGIS Online dashboard, Excel/CSV дата, уулын цулын шилжилтийн мониторингийг
нэг дор нэгтгэсэн веб систем.

## Бүтэц

```
emc_system/
├── backend/            FastAPI + SQLAlchemy (SQLite → PostgreSQL руу шилжүүлж болно)
│   ├── app/
│   │   ├── main.py             API сервер, frontend/dist-ийг үйлчилнэ
│   │   ├── models.py           Хэлтэс, Dataset, Record, MonitoringPoint, Measurement
│   │   ├── seed.py             4 хэлтсийн жагсаалт (нэр, өнгө, ArcGIS линк энд засна)
│   │   ├── routers/            departments, datasets, dashboards, displacement, analytics
│   │   └── services/
│   │       ├── arcgis.py       ArcGIS Online: dashboard тодорхойлолт, live асуулга, шүүлтүүр → SQL
│   │       ├── importer.py     Excel/CSV унших
│   │       └── displacement.py Шилжилт, хурд, хурдатгал, Fukuzono урьдчилсан тооцоо
│   └── tests/
├── uuliin_tsul/        Цулын шилжилтийн 3D апп (`out/` хавтсыг сервер үйлчилнэ)
└── frontend/           React + TypeScript + Vite, Leaflet (+esri-leaflet) газрын зураг, Recharts график
    └── src/dashboard/  ArcGIS dashboard-ыг системийн загвараар зурагч (layout, виджет, шүүлтүүр)
```

## Ажиллуулах

**Хурдан:** `start.bat` дээр давхар дарна → http://localhost:8000

**Хөгжүүлэлтийн горим** (код засахад шууд шинэчлэгдэнэ):

```powershell
# 1-р терминал
cd backend
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000

# 2-р терминал
cd frontend
npm run dev        # → http://localhost:5173
```

Шинэ компьютер дээр анх суулгах:

```powershell
cd backend;  python -m venv .venv;  .venv\Scripts\pip install -r requirements.txt
cd ..\frontend;  npm install;  npm run build
cd ..\uuliin_tsul;  npm install;  npm run build
```

`uuliin_tsul/` нь «Цулын шилжилт» цэсний 3D апп (Next.js, ArcGIS Maps SDK). Хуулбарын эх нь
`monmapgisteam-oss/EMC` репо. Ялгаа нь `next.config.mjs` дахь `output: "export"`, шөнийн горимын
номин ногоон өнгө (`app/globals.css`, `lib/config.ts`), үндсэн горим шөнийнх.
Статик файлуудыг сервер нэвтэрсэн хэрэглэгчид л үйлчилнэ.

## Нэвтрэлт

Систем бүхэлдээ нэвтрэлт шаарддаг (`/api/*` бүх хүсэлт). Нэвтрэх хоёр арга:

1. **ArcGIS Online (EMC) эрх — үндсэн.** Хэрэглэгч ArcGIS Online-ы нэр, нууц үгээрээ нэвтэрнэ. Сервер
   ArcGIS-ээс token авч, хэрэглэгч **Эрдэнэт үйлдвэрийн байгууллагад** (`orgId = iErGCwr6emXIFjPR`) хамаарах эсэхийг
   шалгана — өөр байгууллагын эрхийг нэвтрүүлэхгүй. Нууц үг серверт хадгалагдахгүй; ArcGIS token нь сессэд
   хадгалагдаж, хэрэглэгч **өөрийн эрхтэй хаалттай dashboard-уудыг** шууд харна.
2. **Дотоод эрх — нөөц.** Интернет / ArcGIS ажиллахгүй үед админ нэвтрэх:

   ```powershell
   cd backend
   .venv\Scripts\python -m app.users add admin --name "Систем админ" --admin
   .venv\Scripts\python -m app.users list
   ```

Сесс 12 цаг хүчинтэй (HttpOnly cookie). Нэг нэрээр 10 минутад 5 удаа буруу оролдвол түр хаагдана.
HTTPS дээр ажиллуулахдаа `EMC_COOKIE_SECURE=1` тохируулна.

## ArcGIS Online dashboard-ууд

Систем ArcGIS dashboard-ыг iframe-ээр биш, **өөрийн загвараар дахин зурна**:

1. Dashboard-ын JSON тодорхойлолтыг (layout, виджет, шүүлтүүр) ArcGIS-ээс уншина.
2. Виджет бүрийн асуулгыг (статистик, бүлэглэлт, эрэмбэ, шүүлт) feature service рүү **шууд** илгээнэ —
   ArcGIS дээр дата шинэчлэгдэхэд систем дээр ч шууд харагдана (2 мин кэш).
3. Толгойн шүүлтүүр, графикийн сонголт бусад виджетийг ArcGIS-тэй адил шүүнэ.
4. Газрын зураг нь webmap-ын давхарга, тэмдэглэгээг (renderer) хэвээр харуулна.

Дэмжих виджет: Indicator, Serial chart, Pie chart, Map, List, Table, Details, Gauge, Rich text,
Category selector, Date selector. Газрын зургийн хүрээгээр шүүх (geometry) одоогоор дэмжигдээгүй.

### Байгаль орчны самбарууд

`backend/app/services/env_extras.py`, `plant_dashboards.py`:

- **Хоорондын шүүлтүүр:** шүүлтүүр, график, дугуй диаграм, газрын зураг бие биенээ шүүнэ. Газрын зураг дээрх цэг дээр дарж
  сонгоно, дахин дарвал арилна. Өөр давхаргын талбарыг ArcGIS-ийн одоогийн холбоосоос авдаг тул байхгүй талбараар шүүхгүй.
- **Байрлал, загвар:** дээр картууд, дунд газрын зураг, доор графикууд. Табтай графикууд таб хэвээр, табын товчнууд бүгд
  харагдана, ⊞ нь бүх табыг дэлгэц дүүрэн торонд гаргана. `keepSizes` нь автомат дүрмийн оронд заасан харьцааг хэрэглэнэ.
- **Газрын зураг (2D):** цэг бүр ArcGIS Firefly тэмдэг: Цагаан тоос цэнхэр, Ус усан цэнхэр, Хөрс нил ягаан, Агаар цагаан. Суурь
  зураг нь World Imagery Firefly, цэснээс сольж болно. Өнгийг `env_extras.py`-ийн `_firefly`, зургийг `dashboard.css`-ийн
  `.dw-firefly-*` заана. Ойрхон цэгүүд нэг тэмдэг болж харагдана. Хэрэглэгч талбараар өнгөлөхийг сонговол дугуй тэмдэг гарна.
- **Стандартын шугам:** Ус MNS 4585:2024, Хөрс MNS 5850:2019, Агаар MNS 4585:2016, Баяжуулах үйлдвэрийн ус MNS 4943:2015
  (улаан) ба MNS 6148:2010 (улбар шар). Усны хоёр самбарт pH-д шугамгүй. Утгыг солиход дээрх файлын хүснэгтийг засна.

### Ачаалах хурд

- Нэг дор гарсан, нэг эх үүсвэрийн виджетүүдийн асуулга нэг HTTP хүсэлтээр (`/query-batch`) явна: өөр давхарга удаан бол хүлээхгүй. Backend ижил нөхцөл, бүлэглэлттэй
  статистикийг нэг ArcGIS асуулгад нэгтгэж, үлдсэнийг зэрэг асууна. Нуугдсан табын статистик ч хамт ирнэ.
- Хөтөч сүүлд харсан хариугаа шууд харуулж, ард нь шинэчилнэ. Гарах үед цэвэрлэгдэнэ.
- Dashboard, давхаргын тодорхойлолт 10 минут кэшлэгдэж, дараа нь хуучнаар хариулж ард нь шинэчлэгдэнэ (24 цаг хүртэл).
- Монголоос ArcGIS хүртэл нэг асуулга ~270 мс. Холболт 60 секунд сул байвал дараагийн нээлтэд ~0.5 сек нэмэгдэнэ.
- Өдөр тутам `npm run build` хийгээд 8000 портоор ажиллуулна: `npm run dev` нь кодын файл бүрийг тусад нь ачаалж, газрын
  зургийн хүсэлт давхар явдаг тул илүү удаан. `start.bat` нь `frontend/dist` байвал дахин build хийдэггүй.

### Баяжуулах үйлдвэрийн самбар

«Баяжуулах үйлдвэр» бүлгийн «Ус», «Агаар» нь ArcGIS дээр dashboard item-гүй: «Хүрээлэн буй орчин / Ус»-ын бүтцээр
`backend/app/services/plant_dashboards.py`-д бүрдэж, `Ус_баяжуулах_үйлдвэр`, `Агаар_баяжуулах_үйлдвэр` feature
service-ээс шууд уншина. Үзүүлэлт нэмэх, нэр засахад тэр файлын хүснэгтүүдийг өөрчилнө.

### Хаалттай (private) dashboard

33 dashboard-аас 15 нь бүрэн нээлттэй, 18 нь өөрөө эсвэл өгөгдлийн давхарга нь хаалттай. Тэдгээрийг харуулахын
тулд серверийг ArcGIS эрхтэйгээр асаана:

```powershell
$env:EMC_ARCGIS_USERNAME = "<хэрэглэгчийн нэр>"   # dashboard-уудад хандах эрхтэй хэрэглэгч
$env:EMC_ARCGIS_PASSWORD = "..."
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

Эсвэл бэлэн token: `EMC_ARCGIS_TOKEN`. Байгууллага SSO (enterprise login) ашигладаг бол ArcGIS дээр
хэрэглэгчийн token үүсгэж `EMC_ARCGIS_TOKEN`-д өгнө. Анхааруулга: token нь газрын зургийн давхарга ачаалахад
браузер руу дамжина — системийг зөвхөн дотоод сүлжээнд ажиллуулна.

Бүх dashboard-ын төлөвийг шалгах (сүлжээ шаардлагатай):

```powershell
cd backend
.venv\Scripts\python -m tests.check_dashboards
```

## Дата оруулах

- **Хэлтсийн дата:** тухайн хэлтсийн хуудас → «Дата оруулах». Excel (.xlsx, олон хуудастай бол хуудсаа сонгоно)
  эсвэл CSV. Эхний мөр нь баганын нэр байна. `Огноо/Date`, `Lat/Өргөрөг`, `Lon/Уртраг` баганыг автоматаар таньж
  цаг хугацааны график болон газрын зурагт ашиглана.
- **Шилжилтийн хэмжилт:** «Уулын цулын шилжилт» → «Хэмжилт оруулах». Баганууд:

  | point_code | measured_at         | x (E, м)    | y (N, м)     | z (H, м) |
  |------------|---------------------|-------------|--------------|----------|
  | P-01       | 2026-10-01 08:00    | 500123.4521 | 5430456.7812 | 1302.114 |

  Давхардсан (цэг + огноо) хэмжилтийг алгасна, шинэ цэгийг автоматаар бүртгэнэ. Цэгийн lat/lon, хэсэг, босгыг
  `PUT /api/displacement/points/{id}`-ээр нэмнэ.

## Шилжилтийн дүн шинжилгээ

| Үзүүлэлт | Тооцох арга |
|---|---|
| Шилжилт | Эхний хэмжилтээс хойших dE, dN, dZ, хэвтээ, 3D (мм) |
| Хурд | Сүүлийн N хоногийн (1/3/7/14) 3D шилжилтэд шугаман регресс, мм/хоног |
| Хурдатгал | Хурдны цуваанд мөн адил регресс, мм/хоног² |
| Чиглэл | Хэвтээ шилжилтийн азимут, хойд зүгээс |
| Нуралтын урьдчилсан хугацаа | Fukuzono: сүүлийн 10 хэмжилтийн 1/v-д шугам тааруулж 1/v = 0 цэг (R² ≥ 0.6, буурах хандлагатай үед) |
| Төлөв | **Аюултай**: хурд ≥ аюулын босго эсвэл нуралт ≤ 7 хоног · **Анхааруулга**: хурд ≥ анхааруулах босго эсвэл ≤ 30 хоног |

Анхдагч босго нь 3 / 10 мм/хоног. Цэг бүрээр тохируулна. Уурхайн TARP-д заасан утгаар солих шаардлагатай.
